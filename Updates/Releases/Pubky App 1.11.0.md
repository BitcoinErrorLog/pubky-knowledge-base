# Pubky App 1.11.0

**Date:** 2026-09-23  
**Status:** shipped; Passport behind deployment configuration

Added Pubky Passport sign-in/sign-up, PWA install/offline/update improvements, native sharing, mention previews, hashtag-to-tag conversion, and video-link classification. Passport is visible only when `PUBKY_RUNTIME_PASSPORT_URL` is configured.

Source: [Pubky App 1.11.0 public release](https://github.com/pubky/pubky-app/releases/tag/v1.11.0).
