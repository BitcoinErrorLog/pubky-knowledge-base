# Pubky SDK September 2026

**Date:** September 2026  
**Status:** shipped through Homeserver/Core releases

The SDK gained path-addressed requests and public two-stage authentication in Homeserver 0.12.0, then configurable error-response limits and oversized-payload guards in 0.13.0. These are released SDK changes, not draft protocol work.

Source: [Pubky SDK September 2026 public release](https://github.com/pubky/pubky-homeserver/releases).
