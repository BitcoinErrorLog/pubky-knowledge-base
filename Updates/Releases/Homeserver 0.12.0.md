# Homeserver 0.12.0

**Date:** 2026-09-14  
**Status:** shipped

Added path-addressed SDK requests, public two-stage auth, configured PKARR relay republishing, a Homeserver CLI, Retry-After on 429 responses, auth/host metrics, and a client read timeout. Docker now defaults to the Homeserver target.

Source: [Homeserver 0.12.0 public release](https://github.com/pubky/pubky-homeserver/releases/tag/v0.12.0).
