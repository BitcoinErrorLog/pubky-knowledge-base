# Pkarr 8.0.1 and 8.0.2

**Dates:** 31 August and 23 September 2026
**Status:** shipped

Pkarr 8.0.2 added release automation that publishes crates, npm packages, and relay binaries; `relay --version`; relay response logging; an HTTP/1 connection-buffer limit; and removal of the Nix flake. The published npm package is `@synonymdev/pkarr` 8.0.2.

Source: [Pkarr releases](https://github.com/pubky/pkarr/releases).
