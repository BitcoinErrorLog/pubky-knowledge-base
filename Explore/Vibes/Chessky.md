# Chessky

**Status:** public experiment, version 0.1.0, production stack.

[Chessky](https://chessky-ten.vercel.app) is asynchronous multiplayer chess whose game state is written to and synchronized directly between players' Homeservers. It deliberately uses no Chessky backend, indexer, or aggregator.

Sources: [Vibes board](https://vibes.pubky.app), [repository](https://github.com/gcomte/chessky).
