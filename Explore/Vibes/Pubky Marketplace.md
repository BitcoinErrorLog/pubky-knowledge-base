# Pubky Marketplace vibe

**Status:** public pre-production experiment, board version 0.6.11.

[Pubky Marketplace](https://shop.pubky.app/marketplace) lets people create shops and listings, browse fixed-price and auction offers, and communicate through buyer-seller messaging. Listings and shops are published to seller-owned Homeservers. The durable transaction and payment stack is deployed to staging; Bitcoin uses regtest and fiat uses test/sandbox processors. It has not had an independent security review and is not ready for real funds.

See [[Explore/Projects/Pubky Marketplace|Pubky Marketplace]] for the full status.

Sources: [Vibes board](https://vibes.pubky.app), [project map](https://github.com/BitcoinErrorLog/pubky-marketplace), [Shop repository](https://github.com/BitcoinErrorLog/pubky-shop).
