# Eventky

**Status:** public proof of concept, version 0.1.0, modified staging stack.

[Eventky](https://159.69.22.174/calendar) adds events, calendars, and RSVPs as custom Pubky App post kinds. Its modified Nexus indexes post kinds generically, so it demonstrates an experimental extension rather than behavior available in the standard stack.

Sources: [Vibes board](https://vibes.pubky.app), [App repository](https://github.com/gillohner/pubky-app), [Nexus fork](https://github.com/gillohner/pubky-nexus/tree/feat/custom-post-kinds).
