# Graph Explorer

**Status:** public experiment, version 0.1.0, modified production stack.

[Graph Explorer](https://graph.scriptlesslabs.com/graph) visualizes follows, replies, tags, neighborhoods, searches, and shortest paths in the Pubky social graph. It reads from a Nexus fork with extra graph endpoints; sign-in and writes use the production stack.

Sources: [Vibes board](https://vibes.pubky.app), [App fork](https://github.com/SHAcollision/pubky-app), [Nexus fork](https://github.com/SHAcollision/pubky-nexus/tree/vibe/graph-explorer).
